# 🔐 PassLY - Password Manager

PassLY is a modern full-stack password management application that allows users to securely store, manage, and organize website credentials in one place. It features a clean and responsive UI with full CRUD functionality.

## 🌐 Live Demo

🔗 https://minar-password-manager.vercel.app

## 📂 GitHub Repository

🔗 https://github.com/minar-hossain82/password-manager-using-react

---

# ✨ Features

- 🔐 Store website credentials securely
- ➕ Add new passwords
- ✏️ Edit existing passwords
- 🗑️ Delete saved passwords
- 👁️ Show/Hide password
- 📋 Copy password to clipboard
- 🔔 Toast notifications for user actions
- 📱 Fully responsive design
- ⚡ Fast and clean user interface

# ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/minar-hossain82/password-manager-using-react.git
```

### Go to Project

```bash
cd password-manager-using-react
```

### Install Frontend

```bash
cd passop
npm install
```

### Install Backend

```bash
cd ../passop-mongo
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000

MONGODB_URI=your_mongodb_connection_string
```

---

# ▶️ Run Locally

### Start Backend

```bash
cd passop-mongo
npm run dev
```

### Start Frontend

```bash
cd passop
npm run dev
```
